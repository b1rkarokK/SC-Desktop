# Если SoundCloud не открывается: обход, свой сервер, прокси

Всё настраивается в **Настройки → Сеть**. Есть три способа, пробуйте по порядку.

## 1. Встроенный обход (ничего не нужно)

Выберите **«Прямое подключение»** и нажмите «Применить». «Обход блокировки SoundCloud» оставьте на **«Авто»**.

Программа сама заметит, что SoundCloud не открывается, и начнёт прятать от провайдера имя сайта. VPN, «запрет» и чужие сервера не нужны.

Не помогает, если провайдер блокирует сервера SoundCloud по адресу. Тогда переходите к способу 2.

## 2. Свой сервер (VPN прямо в программе, сама VPN-программа не нужна)

Подходит, если у вас есть VPN-подписка (Happ, Koala, v2rayN, Hiddify и т.п.). Через сервер пойдёт **только SoundCloud**, остальной интернет не трогается.

1. Оставьте **«Прямое подключение»**.
2. В блоке «Свой сервер»:
   - вставьте ссылку на подписку (`https://…`) или на один сервер (`vless://…`, `trojan://…`) и нажмите **«Загрузить»**;
   - **или**, если у вас стоит Koala либо другая Clash-программа, нажмите **«Взять из VPN-программы»**: сервера возьмутся из неё самой.
3. Выберите сервер в списке. В первый раз скачается движок (около 30 МБ).
4. Внизу должно появиться «Подключено». Если сервер не открывает SoundCloud, программа сама его отключит и скажет об этом. Тогда выберите другой.

Частые проблемы:
- **«Сервис отдаёт сервера только своим программам»**: ваш VPN-сервис не даёт подписку чужим программам. Нажмите «Взять из VPN-программы» (если стоит Koala) или вставьте ссылку на один сервер. В Happ её можно скопировать долгим нажатием на сервер.
- В списке есть сервера с пометкой «не поддерживается» (протоколы xhttp и новое шифрование VLESS). Выберите любой другой.
- Ссылка подписки хранится в защищённом хранилище Windows.

## 3. Прокси от VPN-программы (если VPN-программа всё равно включена)

1. Включите VPN-программу и подключитесь к серверу.
2. Узнайте её локальный порт:

| Программа | Где смотреть | Обычно |
|---|---|---|
| Happ | Настройки → «Дополнительные настройки» → «SOCKS5 прокси» | 10808 |
| v2rayN | внизу окна «socks:10808» | 10808 |
| Koala Clash, Clash Verge | Настройки → «Порт» / «Mixed Port» | 7890 / 7897 |
| NekoBox, Hiddify | Настройки → «Порт прокси» | 2080 / 12334 |

3. В SC Desk выберите **«Прокси»**, впишите `socks5h://127.0.0.1:ПОРТ`, нажмите **«Проверить»**, потом **«Применить»**.

**Важно:** пока выбран «Прокси», программа работает только при включённой VPN-программе. Выключили VPN, и в SC Desk будет «Сеть недоступна: error sending request». Тогда верните **«Прямое подключение»** и нажмите **«Применить»**. Без нажатия «Применить» выбор не сохранится, и после перезапуска снова будет прокси.

Если режим TUN (он же «VPN-режим») в VPN-программе включён, ничего настраивать не нужно: оставьте «Прямое подключение».

### Если порт не найти

Откройте PowerShell при включённом VPN и вставьте:

```powershell
Get-NetTCPConnection -State Listen -LocalAddress 127.0.0.1 | Select-Object LocalPort, @{n='Программа';e={(Get-Process -Id $_.OwningProcess).ProcessName}} | Sort-Object Программа
```

Число рядом с вашей VPN-программой и есть порт.

## Частые ошибки

- **«Сеть недоступна: error sending request»**: выбран «Прокси», а VPN-программа выключена. Верните «Прямое подключение» и нажмите «Применить».
- **«Трек закрыт в вашей стране»**: включите «Свой сервер» или прокси с сервером в другой стране (США, Германия).
- **Ошибка 403 при проверке прокси**: SoundCloud не пускает этот сервер. Выберите другой.
