# ПК и Android: что где есть

Правило: любое изменение на ПК проверяется на Android. Баг есть и там: чиним. Такой логики на телефоне нет: пишем «не нужно». Общие тестовые данные лежат в `shared-tests/`, их читают и Rust-тесты, и Kotlin-тесты (расхождение ломает тесты).

| Что | ПК | Android | Как сверяется |
|---|---|---|---|
| Шифрование связи (XChaCha20-Poly1305) | `sync/crypto.rs` | `Crypto.kt` | `shared-tests/crypto.json`, тесты в обеих |
| Настроения волны (слова) | `wave_vibe.rs` | `VibeWords.kt` (делается из Rust-файла скриптом `genvibes.mjs`) | тесты `wave_vibe::tests` и `VibesTest` |
| Подбор волны | `wave.rs`, `wave_model.rs` (обучаемая модель, журнал прослушивания, соседи по плейлистам, слух) | `Wave.kt` (простая часть: лайки, «похожие», настроение, не повторять артиста) | не сверяется, у телефона упрощённая версия |
| Эквалайзер (10 полос, пресеты) | `player/eq.rs`, `eq_popover.ts` | `Eq.kt`, `EqScreen.kt` | формат `EqConfig`, тесты `EqTest`; настройки общие по связи |
| Вход по QR, связь устройств, «Играть на…» | `devices.rs`, `devices_popover.ts`, настройки | `Pairing.kt`, `Link.kt`, `Screens.kt` | одни и те же сообщения JSON (описаны в шапке `devices.rs`) |
| Обновление из приложения | `updater.rs` (Tauri) | `Updater.kt`, `UpdateDialog.kt` | у каждой платформы свой канал выпуска |
| Обход блокировок | `net/bypass.rs`, `net/doh.rs`, свой сервер (sing-box) | `Bypass.kt`, `Doh.kt` (дробление приветствия TLS, адреса по DoH, зеркала картинок); туннель через sing-box ещё не сделан | живые проверки на устройствах |
| Текст песни, итоги, темы | есть | `Extra.kt` (текст из lrclib, итоги из локальной истории, 3 темы) | не сверяется |
| Друзья, общие плейлисты, комнаты, поиск по тексту | есть | `Social.kt`: через ПК по связи (rpc), сам телефон не участник | описано в HANDOFF |
| Жанры, дубли | есть | не сделано | нужно решить |
| Кнопка «Искать текст заново», перевод строк | есть | нет (текста песен на телефоне пока нет) | не нужно до текстов |
| Журнал прослушивания, «слух» кандидатов | есть | не нужно (в волне телефона не используется) | `listening.rs`, `wave_ear.rs` |
